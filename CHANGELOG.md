# Changelog

All notable changes to `DirectDriveMotorControl` will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-25

### Added
- Initial open-source release of **DirectDriveMotorControl**.
- 直驱电机测风扫描运动控制上位机（Qt 5 / C++，Modbus RTU 串口控制）。
- Full documentation set (README, features, structure, build & run, dependencies,
  usage, notes, architecture) and architecture/flow diagrams.
- MIT license and contribution guidelines.

### Changed
- Sanitized all branding to `Felix` / `FELIX` prefix.
- Replaced machine-specific absolute paths with portable placeholders.
